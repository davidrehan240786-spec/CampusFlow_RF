# 🚀 CampusFlow

### Smart Campus Marketplace & Lost–Found Platform

CampusFlow is a campus-exclusive platform where students can **buy, sell, donate items, and recover lost belongings** through a trusted and secure network.

---

## 🧠 Overview

CampusFlow brings together:
- 🛒 A student-only marketplace  
- 🔍 A smart lost & found system  
- 📅 Safe meetup scheduling  
- 🏆 A trust-based user system  

---

## 🎯 Problem

Students face:
- ❌ No centralized campus marketplace  
- ❌ Lost items rarely recovered  
- ❌ Unsafe or unverified transactions  
- ❌ Fragmented communication across platforms  

---

## 💡 Solution

CampusFlow provides:
- ✅ Verified student marketplace  
- ✅ Smart matching for lost & found  
- ✅ Safe meetup scheduling  
- ✅ Trust system with badges & score  

---

## ✨ Core Features

### 🛒 Marketplace
- Post items (sell/donate)
- Browse with search, filter, sort
- View item details

### 🔍 Lost & Found (USP)
- Report lost/found items
- Smart match suggestions
- Status tracking: Searching → Matched → Returned

### 📅 Meetups
- Schedule exchanges
- Select campus location & time
- Track upcoming and past meetups

### 🏆 Trust System
- Verified student badge 🎓  
- Trust score (activity-based)  
- Badges (Trusted Seller, Active User)

---

## 🔄 User Flow

### Marketplace
Post Item → Marketplace → User Connects → Meetup → Exchange

### Lost & Found
Report Item → Match Suggestion → Connect → Recovery

---

## ⚙️ Tech Stack

- **Frontend:** React + Vite + Tailwind CSS  
- **Backend:** Firebase (Auth, Firestore, Storage)  
- **Tools:** Git, VS Code  

---

## 🎯 MVP Scope

- Marketplace (CRUD)
- Lost & Found system
- Meetup scheduler
- Basic trust system
